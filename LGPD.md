# Diretrizes de Conformidade LGPD — ImoAI

## 1. Coleta e Tratamento de Dados
- **Dados Coletados:** Nome, número de telefone (WhatsApp), preferências imobiliárias (tipo de imóvel, orçamento, localização pretendida).
- **Finalidade:** Qualificação automatizada e encaminhamento para corretores credenciados para intermediação imobiliária.

## 2. Consentimento
- A primeira mensagem enviada pelo assistente virtual deve incluir aviso claro de tratamento de dados com link/opção de descadastro (ex: digite "PARAR" a qualquer momento).

## 3. Retenção e Exclusão
- Os dados do lead podem ser anonimizados ou excluídos a pedido do cliente através da aba "Configurações" no painel da imobiliária.
